# Planck to Parsec

Short animated physics videos for YouTube: one astonishing, fact-checked fact per video.

- `videos/` finished MP4s. Standard: 2160x3840 (4K vertical), 60 fps, narration plus original music
- `PRODUCTION.md` the daily procedure, style rules and upload steps
- `shorts/` one scene script per video (Python, Pillow, aggdraw, numpy, ffmpeg); `ligo_first_detection.py` is the reference
- `template/build.py` one-command build; `make_narration.py`, `make_audio.py`, `make_cover.py` are its parts
- `scripts/` narration scripts
- `covers/` cover images
- `brand/` channel profile picture, banner and the script that draws them
- `log.md` topics already covered
